# Apple Style Notepad

A simple browser based notepad built as a self-contained HTML file.

## What it does

- Creates and saves notes in the browser with `localStorage`
- Autosaves while typing
- Lets you search notes
- Supports deleting and exporting a note as `.txt`
- Uses a macOS inspired layout with a soft glass sidebar, traffic light window dots, large note title, and lined writing area

## Run it

Open `index.html` in a browser.

No build step, package install, or server is required.

## Keyboard shortcut

`Cmd + N` on Mac or `Ctrl + N` on Windows and Linux creates a new note.
